# Sample files (made up)

Invented example downloads for trying JunoBooks and for the live checks. None of these are real
transactions or real bank exports; they only follow the column layouts banks commonly use.

- `bank/checking-march-2026.csv`: a checking account in the "Details, Posting Date, Description, Amount" layout.
- `bank/checking-march-april-2026.csv`: overlaps the March file (to show duplicates being skipped).
- `bank/card-amex-style-march-2026.csv`: a card where charges are shown as positive amounts.
- `bank/card-split-columns-march-2026.csv`: a card with separate Debit and Credit columns.
